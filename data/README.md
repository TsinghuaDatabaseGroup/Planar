# Planar Data

The Aviation Safety, Vehicle Safety, Finance, and Legal Contracts datasets are distributed separately. Download them from the [Planar data folder on Google Drive](https://drive.google.com/drive/folders/1wMy6zqkUfnq8VQP28U09H8GeW85qHh22?usp=sharing).

This directory includes two prepared JSONL inputs used by the isolated semantic-operator queries. Each line is one JSON record.
